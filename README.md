# vision-pytorch

![PyTorch](https://img.shields.io/badge/PyTorch-EE4C2C?style=flat&logo=pytorch&logoColor=white)
![Status](https://img.shields.io/badge/Status-En%20Desarrollo-yellow)

Este repositorio contiene clases y métodos orientados a modelos de visión con implementación en PyTorch. El objetivo principal es crear una **librería modular y reutilizable** para entrenar modelos de visión, facilitando el proceso de experimentación y fine-tuning de modelos preentrenados.
